# Joyería Torres Torres

Repositorio del proyecto de sistemas de la joyería Torres Torres.

## Contexto

- El negocio usa **SICAR Punto de Venta**, que guarda sus datos en una base **MySQL**.
- Se está explorando un **conector** que lea las ventas de esa base para generar **códigos QR y folios** en los tickets.
